公式カード **1544枚** を採録。日本の食品 **2958件**。特殊能力 **100種**。カードはすべて英語と日本語の2言語。テストカバレッジ **100%**。バーコードバトラーII用のカードは実機で確認済み。

---

バーコードバトラーIIは、バーコードの数字だけからキャラクターやアイテムを決めます。前読み（まえよみ）は、そのうちキャラクターになる読み方の本体側の呼び名で、このプログラムの名前でもあります。maeyomi はその計算を逆向きに解きます。防御力2400の「ぼうぐ」がほしいと指定すれば、本体がそう読むバーコードを求めて印刷します。

生成したバーコードは紙に出る前に必ずもう一度デコーダに通します。印刷したページはラスタライズしてバーコードリーダーで読み直します。印刷したカードは実機のバーコードバトラーIIに通して確認しました。

1991年の初代バーコードバトラーは、同じ数字を独自の方法で読みます。キャラクターはすべて戦士で、体力は19900、攻撃と防御は9900が上限です。2桁の番号は別の表の特殊能力で、IIでは攻撃2倍になる18が、初代では主人公フラグになります。`decode`・`generate`・`cheat` に `--device bb1` を付けると、初代用のカードを作れます。初代用のデコーダは、初代向けの4つのカードリストに載っている113枚を再現します。初代の実機ではまだ1枚も読み取っておらず、初代用のシートにはそのことを記しています。

1993年のバーコードバトラーII²、通称ダブルは読み取り部を持たず、IIからバーコードを受け取ります。基本はIIと同じ読み方ですが、1桁目が7で10桁目が8のバーコードだけは独自の「7読み」で読みます。攻撃と防御は99900まで届き、特殊能力は体力の2つの桁で決まります。`--device double` を付けると II² 用のカードを作れます。出典は [barcodebattler.net](https://barcodebattler.net/bb2c0.html) の「BBIIダブルC0」です。この読み方で、IIのどの読み方でも再現できなかった正伝3の11枚が説明できます。種族は攻撃の100の位から5を引いた数で、[コレクターの報告](https://mevius.5ch.net/test/read.cgi/toy/1226667612/)が正伝3と正伝4の敵カードで確かめています。11枚すべてが合い、100の位が5未満のときの種族はわかりません。すばやさもまだわかっていません。II² には、IIにない職業も2つあります。職業4の僧侶と職業6の聖戦士です。特殊能力の表もII²独自のものです。

1992年のバンダイのファミコン用ソフト「データック ドラゴンボールZ 激闘天下一武道会」は、バーコードリーダー付きで発売されました。`--device dbz` を付けると、このゲーム用のカードを作れます。ゲームは10桁の数字のビットを40ビットの数に並べ替え、そこからキャラクターかアイテム、必殺技のレベル、HP・BP・DPを読み取ります。この規則はゲーム自身のプログラムから読み取ったもので、デコーダは MAME で動くゲームが受け付けた232件のバーコードすべてで一致します。`--character` でゲームに表示される名前か番号を指定してキャラクターやアイテムを選び、`--level` でレベル、`--hp`・`--bp`・`--dp` で数値を指定します。その数値ぴったりのカードが印刷できないときは、`--nearest` を付けると最も近いカードを選びます。数値が十分に高いキャラクターは、ゲームと同じく強い姿に変身します。データックの実機ではまだ1枚も読み取っておらず、このゲーム用のシートにはそのことを記しています。

1993年のバンダイのデータック第2弾「データック ウルトラマン倶楽部 スポ根ファイト!」は、バーコードを51種類のタイプと、ゲームが PW・ST・SP と呼ぶ3つの数値に読み取ります。タイプは0から27がウルトラヒーローと怪獣、32以上がアイテムで、数値はどれも0から9900まで100刻みです。`--device ultraman` を付けると、このゲーム用のカードを作れます。`--character` でゲームに表示される名前か番号を指定してタイプを選び、`--hp`・`--st`・`--df` でこの順に3つの数値を指定します。この範囲の値はすべて印刷できます。この規則はゲームのプログラムから読み取ったもので、MAME で動くゲームそのものと、発売された38枚すべて、そしてタイプごとに1つずつ作った51件のバーコードで一致します。データックの実機ではまだ1枚も読み取っていません。

同じく1993年の「データック SDガンダム ガンダムウォーズ」は、バーコードを63機のモビルスーツか59枚のコマンドカードのどれかに読み取ります。モビルスーツは機体ごとの HP・AP・DP・CP に表のボーナスを足し、2種類ずつの近距離武器と遠距離武器から1つずつを持ちます。コマンドカードは効果と消費 CP を持ちます。`--device sdgundam` を付けると、このゲーム用のカードを作れます。`--character` で名前・型番・番号を指定してカードを選び、`--hp`・`--st`・`--df` で HP・AP・DP を、`--pick sr=1`・`--pick lr=5`・`--pick cp=11` で武器と CP を指定します。ゲームが持てる2つの値の間の数値は最も近い値になり、コマンドはそのことを伝えます。ルパン三世、ドナルドダック、スパイダーマン、アリスのペイントアドベンチャー、そしてドラえもんの3本には、カードは1枚も付属していません。エポック社はエキサイトステージ'94のために、1994年のJリーグ12クラブの登録選手リストのカードを作りました。バーコードは [barcodebattler.co.uk が公開しているスキャン](https://www.barcodebattler.co.uk/scans/Japan/J-League/)から読み取り、エキサイトステージ'94と'95はどちらもそれぞれをアイテムカードとして読みます。1枚ずつ MAME で確かめました。この規則は MAME 上のゲームと、発売された76件のバーコードすべて、そしてスロットごとに作った122件で一致します。データックの実機ではまだ1枚も読み取っていません。

同じく1993年の「データック 幽遊白書 爆闘暗黒武術会」は、バーコードを22人のキャラクターか10枚のアイテム、そしてゲームが隠しているもう1人のキャラクターのどれかに読み取ります。キャラクターの HP と SP はキャラクターごとに決まっていて、バーコードでは変わりません。バーコードで決まるのは、4つの技のうちどれを使えるかです。アイテムは4段階のレベルに応じて HP か SP を上げるか、対戦モードのルールを変えます。`--device yuyu` を付けると、このゲーム用のカードを作れます。`--character` でカードを、`--pick moves=15` で技を1ビットずつ、`--pick level=3` でアイテムのレベルを指定します。この規則は MAME 上のゲームと、発売された37枚すべて、そしてすべてのキャラクター・マスク・アイテムにわたって作った183件で一致します。データックの実機ではまだ1枚も読み取っていません。

1994年の「データック Jリーグ スーパートッププレイヤーズ」は、バーコードを1993年の Jリーグ10クラブの選手150人か、そのクラブのどれかに読み取ります。カードは実在の選手を選ぶだけで自分の数値を持たないので、選手の能力はゲームが持っていて、このゲームには隠しコマンドのカードがありません。`--device jleague` を付けると、このゲーム用のカードを作れます。`--character` で名前か番号を指定して選手かクラブを選びます。この規則は MAME 上のゲームと、発売された160件のバーコードすべて、そしてゲームが許すすべての折り返しの値に届くよう作った12件で一致します。データックの実機ではまだ1枚も読み取っていません。

データックの「クレヨンしんちゃん オラとポイポイ」は、プログラムにバーコードを読む処理がまったくないので、カードを使えません。

データックの「バトルラッシュ ビルドアップロボットトーナメント」は、ロボ工場で順に読ませる2枚のカードからロボットを作り、`--device battlerush` を付けるとその2枚を作れます。1枚目はロボットの番号、頭、体、肩、足、パイロットを、2枚目は武器と4つのレベルを持ちます。ゲームはお店のバーコードをわざと受け付けません。ゲーム用のカードの最後のけたは、EAN のチェック用の数字より1か2小さいので、カードはそのけたのまま印刷され、ふつうのバーコードリーダーでは読めません。`--character` で番号か16人の対戦相手の名前でロボットを、`--pick head=3 --pick attack=7` などで部品とレベルを選びます。この規則はゲームのプログラムから読み取り、試したすべての組で MAME 上のゲームと一致します。MAME はセーブ用のチップを一部しか再現していないため、確認ではその2バイトを書き込んで工場まで進めています。バンダイが印刷したカードの一覧は知られていません。

1992年のサンソフトのファミコン用ソフト「バーコードワールド」は、ファミコンにつないだバーコードバトラーIIでカードを読むので、どのバーコードも読めます。`--device barcodeworld` を付けると、このゲーム用のカードを作れます。ゲームはバーコードバトラーIIとほぼ同じように数字を百の位で読み、HP は49900まで、ST と DF は19900までです。体力が19900を超えるには百の位が9で、すばやさが5でなければなりません。魔法と薬草は職業で決まります。`--character` で戦士か魔法使いを、`--hp`・`--st`・`--df` で数値を、`--pick job=3`・`--pick speed=8`・`--pick ability=45` で職業・すばやさ・能力を指定します。この規則は MAME 上のゲームと、発売された24枚を含む211件、そしてここで作って試したすべてのカードで一致します。

1993年のエポック社のスーパーファミコン用ソフト「バーコードバトラー戦記」は、バーコードバトラーII インターフェイスにつないだバーコードバトラーIIでカードを読み、`--device senki` を付けるとこのゲーム用のカードを作れます。数字の読み方はバーコードワールドと同じで、違いは3つです。8けたのバーコードは前に0が5つ付いて届きます。インターフェイスがバーコードバトラーIIの空白を0に変えるからです。後ろから読むアイテムは、ST の一の位が10未満に収まります。そしてインターフェイスの箱に印刷されたバーコードは、対戦モードではカードにならずサウンドテストを開きます。この規則は MAME 上のゲームと、ここで作って試したカードを含む253件で一致します。シナリオモードの隠れた店ブラックストアは、後ろから読むカードを小さいずらし幅で読むので、そういうカードには店での HP・ST・DF も載せます。この読み方は MAME 上のゲームと232件で一致します。確かめるときは店まで歩かず、店のマップイベントが立てるフラグを直接立てました。MAME 0.289 はスーパーファミコンに各けたを1ビットずれて送るため、確認には専用に書いたインターフェイスでゲームにバーコードを渡しています。

エポック社のスーパーファミコン用ソフトのうち4本は、同じインターフェイスでパスワード画面からバーコードを読み、1つのコードが決まった一覧から1つの効果を起こします。キャラクターにはなりません。「ルパン三世 伝説の秘宝を追え!」は `--device lupin`、「ドナルドダックの魔法のぼうし」は `--device donald`、「スパイダーマン リーサルフォーズ」は `--device spiderman`、「アリスのペイントアドベンチャー」は `--device alice` です。効果はノーダメージ、無限のライフ、アイテム最大などの裏技、ステージや章やエンディングへのジャンプ、サウンドテストです。`maeyomi kinds --device lupin` でそのゲームの効果の一覧を表示し、`--character` で名前か番号で1つ選びます。どの規則もゲームのプログラムから読み取り、試したすべてのコードで MAME 上のゲームと一致します。ルパン三世は250件、ドナルドダックは247件、スパイダーマンは221件、アリスは253件です。どの規則にも合わないコードは、読み込まれても何も起きません。

スーパーファミコン用のドラえもん3本も、同じ読み方でそれぞれ2つの画面からコードを読みます。「ドラえもん2」は `--device doraemon2` でパスワード画面とステージ中の道具メニュー、「ドラえもん3」は `--device doraemon3` でパスワード画面とプレイ中の装備メニュー、「ドラえもん のび太と妖精の国」は `--device yousei` でパスワード画面と町のマップの道具画面です。パスワード画面では無敵、ライフ99、後のワールドなどの裏技が、メニューではひみつ道具、武器、防具、アイテムが手に入ります。どのカードにも、読ませる画面が書いてあります。「ドラえもん4」にも同じ読み取りのプログラムが入っていますが、どこからも呼ばれないので、バーコードを読む画面はありません。

「J.リーグエキサイトステージ'94」は、プレシーズンマッチの前に登録選手画面のバーコードバトラーパネルでコードを読み、`--device excite94` を付けるとこのゲーム用のカードを作れます。チェック用の最後のけたが4以上のコードは240人のかくし選手のだれかで、名前と、キック、シュート、ラン、ドリブル、キーパーならディフェンスのランクを持ちます。4未満はエキサイトステージ'95と同じようなアイテムカードです。`--character` で選手かアイテムを、`--pick value=253` でアイテムの量を選びます。名前とランクはゲーム自身の表から取り、どのコードのけたでも届かない1人を除いて、全員を印刷できます。PKモードは選手を同じように読み、アイテムカードは6種類のPKアイテムのどれかと0から9のレベルとして独自に読むので、カードにはそれも載せます。それぞれのPKアイテムが試合で何をするかはまだ調べていません。どちらの規則も、試したすべてのコードで MAME 上のゲームと一致し、PKモードでは168件です。

スーパーファミコン用の「J.リーグエキサイトステージ'95」は、オープン戦、リーグ戦、トーナメント、ドリームマッチの前にバーコードバトラーIIの入力画面でコードを読み、`--device excite95` を付けるとこのゲーム用のカードを作れます。コードはどれもアイテムカードで、総力、ドリブル、パススピード、キックスピード、キーパーのセービングを0から253上げるか、ハンデ4ポイントまで、またはファウルでカードが出なくなる特殊カードです。`--character` でアイテムを、`--pick value=253` で上げる量を選びます。この規則は、試したすべてのコードで MAME 上のゲームと一致します。PK モードは別の読み方をするので扱っていません。

ファルコムの「ドラゴンスレイヤー英雄伝説II」は1993年にエポック社がスーパーファミコンで発売し、タイトルメニューとフィールドのメニューでコードを読みます。`--device dslayer2` を付けると、このゲーム用のカードを作れます。タイトルメニューでは、すべての能力が最大、経験値とゴールドが2倍、モンスターリスト、サウンドモードなどの裏技になります。フィールドでは、038438816で始まるコードが最後の3けたの番号のアイテムを、999ならすべてのワープ先を開き、いくつかのコードは持っていないランプ、ビスナの実、やすらぎのキノコ、地図を使います。エポック社がバーコードバトラーII用に作ったドラゴンスレイヤーのカードを、ゲームは特別には扱いません。

エポック社の1993年の野球ゲーム「はた山ハッチのパロ野球ニュース!実名版」は、バトル野球盤でコードをバトラーとして読み、`--device hatayama` を付けるとこのゲーム用のカードを作れます。エポック社のカードと同じ並びのコードはそのまま読まれ、体力は99900まで、攻撃と防御は百の位で19900まで、魔法使いの魔法は99までです。それ以外のコードは最後のけたから計算されます。`--character` で戦士か魔法使いを、`--hp`・`--st`・`--df` で数値を、`--pick mp=99` で魔法を選びます。同じコードの最後のけたは、ゲームのほかの2つのバーコード画面で作戦と絵も選び、カードにはそれも印刷されます。ゲームには14チームのカードが付属していましたが、そのバーコードはだれも公開していません。

## コマンドラインから

上のタブは、すべてコマンドとしても用意されています。

ランダムなカード24枚。A4に9枚ずつ並び、シードを指定すれば何度でも同じ結果になります。

```bash
maeyomi random --count 24 --hp 1000-10000 --st 100-3000 --df 100-3000 \
    --seed 1234 --output cards.pdf
```

数値を指定して1枚だけ作る場合。

```bash
maeyomi generate --name "Fire Knight" \
    --hp 5000 --attack 1800 --defense 1200 \
    --race human --class warrior --ability 17 \
    --output fire-knight.pdf
```

指定した値と実際にできた値を並べて表示するので、違いが出たカードが黙って通ることはありません。

```
Field    Requested       Generated       Difference
---------------------------------------------------
HP       5000            5000
ST       1800            1800
DF       1200            1200
PP       any             5
MP       any             0
Race     human           human
Job      -               0
Class    warrior         warrior
Speed    -               0
Ability  17              17
```

本体と同じ読み方でバーコードを読むには次のようにします。

```bash
maeyomi decode 0401207237501
```

本体は特殊能力を属性名ではなく番号で持っています。一覧はこちらです。

```bash
maeyomi abilities
```

アイテムも同じように作れます。武器は攻撃だけ、防具は防御だけ、おたすけアイテムは体力・薬草・MPのうち1つだけを持ちます。薬草とMPは0から99までの個数です。

```bash
maeyomi generate --name "Herb Pouch" --race support_item --herbs 99 \
    --output herbs.pdf
```

数値のオプションは、正確な値・範囲・上下限のいずれでも指定できます。`5000`、`5000-6000`、`>=1500`、`<=3000` のように書きます。`--images png` を付けると PDF と一緒にページ画像も書き出します。

指定どおりのカードが作れない場合、`generate` はどの項目が原因かを示して何も書き出しません。`--nearest` を付けると、到達できる範囲でもっとも近いカードを作ります。

```bash
maeyomi generate --hp 20900 --st 11000 --df 10000 \
    --race mechanical --nearest --output golem.pdf
```

```
closest card differs by 100 across the requested stats
  df: requested 10000, produced 9900
```

ここでいう距離は、指定した項目に限った体力・攻撃・防御の差の合計です（表示上の単位）。種族・職業・特殊能力・素早さは近似しません。人間がほしいという指定に鳥で答えても仕方がないので、それらが原因で作れない場合は作れないまま返します。

`--back-read` を付けると、本体が後読み（うしろよみ）で読むカードになります。上限は前読みより低く、体力は99900に対して49900までです。4桁が能力値と特殊能力をまとめて決めるため、作れる組み合わせはかなり限られます。

## 動作確認

`maeyomi doctor` は、この環境で本体が読めるカードを印刷できるかどうかを確認し、各項目が何を見たかを表示します。答えの分かっているバーコードを読み、シンボルを描いて PDF から読み直し、日本語フォントが解決できているかを確かめ、配色をコントラストと色覚の基準で測り直し、2種類のカード一覧を数え、動かしている処理系・端末が日本語を表示できるか・空き容量を報告します。本当に問題があるときだけ終了コードが0以外になります。どちらの入れ方をした場合でも最初に実行してください。フォントが解決できていないと、印刷したカードの文字が空白になって初めて分かります。

## 本体が保持している値

出典は [barcodebattler.net](https://barcodebattler.net/) です。数値はデコーダに直接書き込むのではなく、計算の結果として再現しています。

| 項目 | 前読み | 後読み |
|---|---|---|
| 体力 | 0 〜 99900 | 0 〜 49900 |
| 攻撃 | 0 〜 19900 | 0 〜 11900 |
| 防御 | 0 〜 19900 | 0 〜 9900 |
| 特殊能力 | 00 〜 99 | 00 〜 29 |

種族0から4はキャラクターで、順にメカ・動物・海の生き物・鳥・人間です。種族5から9はアイテムです。職業の数字0から6は戦士、7から9は魔法使いです。値は100単位で保持されるため、能力値は必ず100の倍数になります。

指定できる範囲を狭める制約が2つあります。どちらかに当たった指定は、理由を示して断ります。黙って別の値に置き換えることはありません。

- 体力が19900を超えるキャラクターには、公開されている前読みマーカーが必要で、3桁目が9に固定されます。そのカードの体力は必ず900で終わり、素早さは必ず5になります。
- 種族0・1・2は体力20000を超えると攻撃と防御が書き換えられます。そのため、その大きさでは任意の組み合わせに到達できるわけではありません。その中には、表示より大きい、最大24600の攻撃や防御で戦うバーコードもあり、カードにはその値も印刷します。

## しくみ

```
指定した値 -> 桁の配置 -> バーコード -> デコーダ -> 照合 -> 採用
```

前読みは決まった桁の並びを各項目に割り当てているので、逆算は探索ではなく配置です。すべて指定された要求は各桁を一意に決め、チェックディジットを計算すれば候補は1つになります。総当たりなら10^12通りを歩くところです。それでも候補は必ずデコーダに通し、どれか1項目でも食い違えば捨てます。

後読みは一対一ではありません。4桁が体力・攻撃・防御・特殊能力をまとめて決め、種族はチェックディジットの位置にあるため配置できず、空いた桁を調整して合わせにいく必要があります。到達できる集合は小さく、すべて列挙できます。10000通りの桁の組み合わせから、体力の百の位が半分になる関係で5000通りの能力値の組が生まれます。

バーコードはモジュール幅を明示してベクターで描きます。既定値は EAN の標準値である0.33mmです。ラスタライズしたバーコードをレイアウトに合わせて拡大縮小すると、モジュールの幅が不均等に丸められて読めなくなります。これは数字の文字列をいくらテストしても見つかりません。

## 印刷

必ず等倍（100%）で印刷してください。「用紙に合わせる」「縮小して全体を印刷」などの倍率指定はすべて切ってください。拡大縮小されたページは見た目には正しいまま読めなくなります。スキャナが測っているのはモジュールの幅だからです。

カードは縦向き、63.5×88.9mmのポーカーサイズで、A4に9枚並びます。カードスリーブや裁断機が想定している寸法です。これはこのプロジェクトが選んだ寸法です。エポック社は自社カードの寸法を公表しておらず、収集家のページにもオークションの出品にも wiki にも記録がありません。寸法は [`layout.py`](src/maeyomi/rendering/layout.py) の `CARD_WIDTH_MM` と `CARD_HEIGHT_MM` にあり、この2つを変えれば他もすべて追従します。グリッド・間隔・各種マーク・収まりの検査は、いずれもこの2つから導かれています。

シートは印刷所が求める条件に従います。

| 項目 | 値 | 理由 |
|---|---|---|
| 塗り足し | シートで1.5mm、`--print-shop` では3mm | 裁断が少しずれてもインクが残る |
| カード間の間隔 | 4mm（塗り足しの2倍） | 隣と共有せず、カードごとに独立した裁断線になる |
| 安全領域 | 仕上がり線から4mm | 読む必要のあるものが裁ち落とされる位置に来ない |
| トンボ | 塗り足しの端から始まる角のみの目印 | 裁断の基準になり、カードの上を線が横切らない |
| モジュール幅 | 0.330mm | GS1 EAN-13 の標準値 |
| バーの高さ | 22.85mm | GS1 の標準値であり、手で通すときの許容範囲そのもの |

`--print-shop` を付けると、同じカードをもう一つの形で書き出します。1ページに1枚、ページサイズはカードに3mmの塗り足しを加えた大きさ、定規もマークもなし。これは商業印刷所の入稿指定そのものです。

各シートの下部には100mmの定規がセンチ単位の目盛付きで入り、カードの上には各バーコードの正しい幅を英語と日本語で示す一行が入ります。最初の1枚を印刷したら定規を当ててください。短ければプリンタがページを縮小しています。設定を直してもう一度印刷してください。どちらの帯もカードの並びの外側にあるので、裁断すれば一緒に切り落とされます。

## 手元のバーコードを読む

`maeyomi decode 4901085061169` は、任意のバーコードを本体がどう読むかを表示します。`-o card.pdf --name "トマトソース"` を付ければカードも印刷します。ウェブ画面の「バーコードを よむ」も同じで、バーの下に印刷されている数字を入力すると、カードの種類・3つの数値・特殊能力・前読みと後読みのどちらで読まれるかが表示され、そのまま印刷できます。

`maeyomi kinds` は本体が扱うカードの種類を、両方の言語でそれぞれの役割とともに一覧表示します。

実際、当時はこうして遊ばれていました。商品のバーコードはどれもカードになるので、トマトソースの瓶はキャラクターに、スナック菓子の袋は武器になります。日本の商品コードも他と同じように扱えます。`4902102072618`、お茶のボトルは防御力2400の「ぼうぐ」です。

## スーパーマーケット

`maeyomi products --search 茶` は該当する日本の食品を一覧表示し、`--count 9 --seed 3` はランダムに選び、`-o shopping.pdf` で印刷します。ウェブ画面の **スーパーマーケット** も同じで、**おまかせ** ボタンが付いています。トマトソース対ラーメンも立派な勝負です。

この棚は [Open Food Facts](https://world.openfoodfacts.org/) から選んだ部分集合です。日本の企業に割り当てられたバーコード、つまり45と49で始まるものに限り、日本語表記の名前を持ち、デコーダが受け付けるものだけを残しました。元のデータは Open Database License で公開されており、この部分集合も同じ条件を引き継ぎます。帰属は **出典** に記しています。カード上の数値は一切そちらから来ていません。すべてこのプロジェクトのデコーダがバーコードから読み取ったものです。名前が間違っていても、冗談が一つ滑るだけで済みます。

ウェブ画面の `maeyomi decode <barcode>` は Open Food Facts に商品名も問い合わせ、分かれば名前欄に入れます。これは便宜上の機能で、問い合わせが失敗してもカードの内容は変わりません。

## 実在のカード

`maeyomi official --list` はエポック社とバンダイが発売した40のカードリストと、それぞれ何枚印刷できるか、どの本体向けのリストかを表示します。`maeyomi official --set candy -o candy.pdf` で1つを印刷し、`--set` を省略すると1544枚すべてを印刷します。ウェブ画面の **ほんもののカード** も同じです。

エポック社は機械可読な一覧を公開していないため、バーコードは収集家が手元のカードを書き写した [wikiwiki.jp](https://wikiwiki.jp/barcode/) のページから取っています。各項目には出典ページの URL を記録しています。5件はチェックディジットが合いません。つまりどこかの桁が打ち間違いですが、どの桁かは特定できないため、推測で直さずに一覧に残したうえで除外しています。各カードに印刷される数値は wiki からの引き写しではなく、このプロジェクトのデコーダがバーコードから読み取ったものです。

6つのリストは初代バーコードバトラー向けです。最初のセット、魔強軍団ゴッドマーズ出現！、チューハイカーンの逆襲、最後の決戦ゴッドＶＳマザー、バーコードバトラーキャンデー、そして「バーコードバトラー対応」と書かれたコロコロコミックのおぼっちゃまくんのカードです。4つは特殊能力を初代の表で説明しています。ゴッドマーズのリストには数値がありませんが、IIだけが読む魔法使いも薬草やMPのアイテムもありません。正伝3 と 正伝4 はII²の7読みが必要で、正伝4 のカードの半分が7読みです。残りの24のリストはIIの表で印刷します。

ゼルダの伝説、小学二年生の特製カード、ストリートファイターII のカードは、[barcodebattler.co.uk](https://www.barcodebattler.co.uk/) の `deeta.js` にあるカードリストから取っています。英語で公開されているので、カード名も英語です。ゼルダの赤いくすりは、IIのボードゲームのカードでもあります。

ドラゴンスレイヤー英雄伝説、ドラえもん のび太の恐竜、おぼっちゃまくん、明治のカードはどこにも一覧がないため、[barcodebattler.co.uk が公開しているカードのスキャン](https://www.barcodebattler.co.uk/scans/Japan/)から1枚ずつバーコードを読み取り、表面に印刷された数値で名前と結び付けています。明治のカードは1番と5番しかスキャンされていません。

スーパーマリオワールドのセットと、アメリカとカナダでアーウィンが、イギリスとヨーロッパでトミーが売ったセットは、すべてのバーコードを文字で載せている [barcodebattler.co.uk](https://www.barcodebattler.co.uk/) のカードのページから取っています。トミーのカードはエポック社のコードにその国の名前を付けたもので、名前が違う版ごとにリストを分けています。イギリス、アイルランド、イタリアは同じ1つのリストで、ドイツ、スペイン、フランスはそれぞれいくつかのアイテムの名前を変えています。アーウィンのアメリカ版とカナダ版は名前もコードも同じで、カナダ版は英語の横にフランス語もあるだけなので、1つのリストです。アーウィンはアイテムとニュースのカード10枚すべてのコードを変えました。9枚は同じアイテムとして読まれ、ライフクリスタルは表面に数値ではなく「EP = ??」と印刷され、バーコードは300と読まれます。エポック社のカードは1600と印刷され、そのとおりに読まれます。

データック ドラゴンボールZ には40枚のカードが付属していました。[説明書](https://setsumei.cloudfree.jp/famicom/datachdragonballz/datachdragonballz.html)によると、スーパーサイヤ人孫悟空、スーパーサイヤ人トランクス、フリーザ（最終変身）、セル（完全体）などにはバーコードがなく、好きなバーコードを貼って使います。バーコードのある35枚と特別なスーパーサイヤ人孫悟空のカードの36枚を、エミュレータ [puNES](https://github.com/punesemu/puNES) のソースにある一覧から取り、1枚ずつ MAME 上のゲームで読み取ってから加えています。

このゲームは、バーコードの黒いバーと白いすき間の太さがそれぞれ3種類以上あるときだけ読み取ります。プログラムの $B085 で測った太さを種類ごとに分け、それより少ないと読み取りません。太さが1・2・4の3種類のバーコードは、通す速さによって読めたり読めなかったりします。このプログラムがゲーム用に作るバーコードはどの速さでも読め、`maeyomi decode --device dbz` はゲームが読まないバーコードを教え、スーパーマーケットは読めない商品に印を付けます。

データック ウルトラマン倶楽部 には40枚のカードが付属し、そのうち2枚は白紙です。残りの38枚は [retrostuff.org](https://retrostuff.org/2019/03/23/bandai-datach-ultraman-club-spokon-fight-barcodes-for-mame/) が箱入りのセットから読み取ったバーコードで、名前は puNES の一覧に従い、1枚ずつ MAME 上のゲームで読み取っています。後のデータックのゲームはドラゴンボールZのようには読み取りを断らず、太さが2種類しかないバーコードも読みます。共通するのは、黒いバーか白いすき間の太さがちょうど1・2・4のバーコードで、通す速さによって読めないことがある点です。発売されたウルトラマン倶楽部のカードのうち5枚がこれにあたります。このプログラムがデータックのゲーム用に作るカードは、こうしたバーコードを使いません。

SDガンダム ガンダムウォーズ には40枚のカードが付属し、そのうち37枚には下の端にモビルスーツ、上の端にコマンドの2つのバーコードがあり、特別なカード1枚にも1つずつあります。この76件のバーコードは [retrostuff.org](https://retrostuff.org/2019/05/12/bandai-datach-sd-gundam-gundam-wars-barcodes-for-mame/) が箱入りのセットから読み取ったもので、puNES の一覧と一致し、1件ずつ MAME 上のゲームで読み取っています。

幽遊白書 には40枚のカードが付属し、そのうち3枚にはバーコードがありません。残りの37枚は [archive.org](https://archive.org/details/yu-yu-hakusho-bakuto-ankoku-bujutsue-box-front) が全セットのスキャンと一緒に公開している表から取り、名前もその表に従い、1枚ずつ MAME 上のゲームで読み取っています。

Jリーグ スーパートッププレイヤーズ には40枚のカードが付属し、1枚に4つのバーコードがあります。クラブと3人の選手、または4人の選手です。160件のバーコードは [archive.org](https://archive.org/details/j-league-super-top-players-manual) が全セットのスキャンと一緒に公開している表から取り、名前はゲームの選手名鑑に従い、1件ずつ MAME 上のゲームで読み取っています。

バーコードワールド には24枚のカードと白紙のカード1枚が付属していました。バーコードは [barcodebattler.co.uk が公開しているカードのスキャン](https://www.barcodebattler.co.uk/scans/Japan/BarcodeWorld/)から読み取り、名前はカードに印刷されたとおりで、1枚ずつ MAME 上のゲームで読み取っています。武器・防具・アイテムはキャラクター画面ではなく戦いの途中で読ませるので、数値なしでその種類として印刷します。

[日本語版ウィキペディアの記事](https://ja.wikipedia.org/wiki/%E3%83%90%E3%83%BC%E3%82%B3%E3%83%BC%E3%83%89%E3%83%90%E3%83%88%E3%83%A9%E3%83%BC%E6%88%A6%E8%A8%98_%E3%82%B9%E3%83%BC%E3%83%91%E3%83%BC%E6%88%A6%E5%A3%AB%E5%87%BA%E6%92%83%E3%81%9B%E3%82%88!)によると、バーコードバトラー戦記 にはキャラクター5枚、アイテム3枚、白紙2枚の10枚のカードが付属していました。そのバーコードはだれも公開していないので、`maeyomi official --device senki` は空のシートを印刷せず、そのことを伝えます。

## 隠しコマンド

`maeyomi cheat -o cheat.pdf`、またはウェブ画面の「チートカード」のタブを使います。画面のどこかで上・上・下・下・左・右・左・右・B・A と入力しても、このタブが開きます。出てくるのは、体力99900で攻撃が2倍になるメカの魔法使いです。本体の表示は攻撃14600・防御19900で、戦闘では攻撃24600で戦います。

この値はどこにも書き込まれていません。前読みのキャラクターを体力最大で総当たりし、デコーダ自身の計算に通して、未解決の分岐をすべて避けたうえで、戦闘時の攻撃と防御の合計が最も大きいものを残しています。隠れた24600は本体そのものの挙動です。体力20000以上のメカで攻撃の桁が46のとき、表示されないボーナスが加わります。[barcodebattler.net](https://barcodebattler.net/page21.htm) には、4994699095453 のバーコードで実機がまさにそう動いた記録があります。カードには、この隠れた値を特殊能力の横に印刷しています。

`maeyomi cheat --items -o cheat.pdf` を使うと、桁が持てる最大値のアイテムが5枚加わります。攻撃9900の武器、防御9900の防具、体力99900の回復アイテム、薬草99、MP99です。どれも使ったキャラクターに別々の特殊能力を渡します。相手の防御80%ダウン、自分の防御50%アップ、相手の体力50%ダウン、相手の攻撃50%ダウン、相手の特殊能力をすべて無効化、の5つです。複数のアイテムの特殊能力が重なるかどうかは資料に書かれていないため、それを前提にはしていません。

コマンドは、それぞれのアイテムをどの職業が使えるかも表示します。出典は [note.com の解析](https://note.com/sakigomyway_5634/n/n61808a7245e5) の装備相性の表です。魔法使いは武器も防具も装備できないので、剣と盾はどの職業の戦士でも使えますが、隠しコマンドの魔法使いには使えません。回復アイテム・薬草・クリスタルは、隠しコマンドの魔法使いが使えます。

`maeyomi cheat --device bb1 --items -o cheat.pdf` は初代バーコードバトラー向けに同じことをします。すべての数値が上限の戦士、体力19900・攻撃9900・防御9900で攻撃2倍のキャラクターと、上限の武器・防具・回復アイテムです。この戦士は職業9です。初代ではこの職業がすべての武器を装備でき、種類0から4の武器の攻撃が1.5倍になります。

`maeyomi cheat --device double --items -o cheat.pdf` は3つの中で最強です。攻撃99900・防御99900のII²用カードで、これは出典が上限として示す値です。特殊能力は相手の体力を半分にするものです。特殊能力は体力の2つの桁で決まるため、体力は92900になります。アイテムはIIのものを使い、それぞれにII²の表にある特殊能力を持たせています。II²の装備相性の表は公開されていないため、どの職業がどのアイテムを使えるかは表示しません。

`maeyomi cheat --device dbz --items -o cheat.pdf` は、必殺技レベル3、HP99500・BP48250・DP33250 のスーパーサイヤ人の悟空です。HP はゲームの規則が持てる最大値で、BP と DP は、バーコードが10桁の数字として成り立つ組み合わせの中で最も強いものを、印刷できるカードをすべて探して選んでいます。ゲームがプログラムの中に隠しているカードの10倍以上です。アイテムは効果ごとに最も強いもので、仙豆、神龍、神様、最長老、超神水、レベル4のポルンガです。

`maeyomi cheat --device ultraman -o cheat.pdf` は、PW・ST・SP がすべて9900のウルトラマンです。ゲームの2つの表を足して届く最大値です。

`maeyomi cheat --device sdgundam -o cheat.pdf` は、HP・AP・DP の合計が最も大きいモビルスーツ、クイン・マンサで、ボーナスはすべて最大です。HP7700・AP7000・DP9000・CP6 になります。

`maeyomi cheat --device yuyu -o cheat.pdf` は、ゲームが隠しているキャラクター SPトグロで、HP9999・SP9999、4つの技すべてを使えます。ゲームがこのキャラクターを出すのはビットの並びがちょうど1つに決まったときだけで、バンダイが印刷したカードにはありません。

`maeyomi cheat --device barcodeworld -o cheat.pdf` は職業9の魔法使いで、HP49900・ST19900・DF19900、魔法10・薬草5と、どの数値もゲームが読める最大値です。`maeyomi cheat --device senki -o cheat.pdf` は、バーコードバトラー戦記 用の同じ魔法使いです。

パスワード画面の4本では、いちばん役に立つ効果になります。ルパン三世はノーダメージ、ドナルドダックはすべてのパワーとハート12個の空のステージ、スパイダーマンは無限のライフ、アリスのペイントアドベンチャーは物語の後半のフラグがすべて立った最後の場面です。スパイダーマンは3つの効果を別々の場所に覚えるので、無限のライフ、体力2倍、ボスの体力半分を続けて読ませると3つとも残ります。ドラえもん2はライフ99、ドラえもん3はワールド5から、のび太と妖精の国はドラえもんが無敵になります。J.リーグエキサイトステージ'95は、どのカードよりも多い253だけ総力が上がります。ドラゴンスレイヤー英雄伝説IIは、すべての能力が最大で始まります。はた山ハッチは、体力99900、攻撃と防御19900、魔法99の魔法使いです。J.リーグエキサイトステージ'94は、すべてAランクのかくし選手、がまもと くにくにです。データックのバトルラッシュは、攻撃、防御、スピードがいっしょに届く最大の233、回復255のロボットの2枚を印刷します。ゲームの計算の中で1バイトがあふれるので、いちばん大きな部品が最強のロボットになるわけではありません。

## 2つの言語と絵

カードは画面の言語に関わらず、必ず英語と日本語の両方で印刷されます。生き物の種類、戦い方、3つの能力値、特殊能力、読み取り位置の案内、そのすべてが両方の言語で入ります。どの情報にも、まだどちらの文字も読めない子ども向けの絵が付きます。種類を示す色帯と絵記号、能力値のハートと剣と盾、そして特殊能力には何がどちらに変わるかを示す絵記号が入ります。たとえば「自分の攻撃が2倍」なら上向きの矢印が付いた剣です。意味を担うのは矢印の向きで、色ではありません。

特殊能力の文言は両言語とも公開されているものです。日本語は barcodebattler.net/page05.htm からそのまま引用し、英語は同じページをこのプロジェクトが読み取ったものです。種族・職業・能力値の名称はこのプロジェクト独自の訳で、子どもが最初に習うひらがなとカタカナで書いています。プレイヤーが入力した名前は、どちらの文字でも入力どおりに印刷されます。

ウェブ画面は上部のボタンで英語と日本語を切り替え、選んだ言語を記憶します。

日本語はどの PDF リーダーにも入っているフォントで組んでいますが、埋め込みではなく参照です。印刷所に入稿する場合は PDF ではなく `--images png` で書き出したページ画像を送ってください。600dpi で、文字はすでに描画済みです。

## マウスがなくても、目が見えなくても

画面はキーボードだけで操作できます。スキップリンクで見出しを飛ばせ、6つのタブはタブ移動1回分にまとまっていて矢印キーで切り替わり、Home と End で両端に移動します。すべての操作部分にフォーカスの枠が表示され、どれも44×44ピクセル以上あり、食品の一覧はキーボードでスクロールできます。言語の切り替えは文書の `lang` も変えるので、スクリーンリーダーの読み上げも切り替わります。動きを減らす設定が有効な環境では、アニメーションを行いません。

axe-core は6つのタブすべてで、明るい配色でも暗い配色でも、WCAG 2.2 の A と AA に加えて独自のベストプラクティス規則についても違反を報告しません。規則では判定できない部分は実際のブラウザで手作業で確認しました。フォーカスの枠はスタイルシートではなくフォーカス中の要素から読み出して確認しました。

PDF には、構造ツリーなしで持てるものを入れてあります。各ファイルは自分の名前を持つので、読み上げソフトは `sheet.pdf` ではなく「Barcode Battler II card: Tea」と読み上げ、ファイル名よりその題名を優先するよう指定してあります。文書には言語・作成者・内容が宣言されています。カード上の文字はすべて実体のあるテキストです。名前、数値、特殊能力、両方の言語、バーの下の数字まで、すべてファイルから取り出せます。取り出される順序も人が読む順序で、まず種類、次に名前、各数値はそれが何を表すかのラベルの後、続いて特殊能力、最後にバーコードです。

入っていないものもあります。ReportLab はタグツリーを出力しないので、これらは PDF/UA ではありません。見出しもリストもなく、絵記号に代替テキストは付いておらず、日本語の部分に個別の言語指定もありません。絵記号は隣の文字が言っていることを繰り返しているだけなので、説明がなくても失われる情報はありません。検証ツールはこれらをタグなしと判定します。

## 色

カードは印刷所に出すことが多く、その場合は白黒で刷られることも珍しくありません。また渡す相手は子どもで、男の子のおよそ12人に1人は赤と緑を見分けません。どちらも測定で対処しています。

色だけで区別されるものはありません。どの色帯にも名前と絵記号があり、どの能力値にも固有の形と2文字のラベルがあるので、白黒で印刷したカードも色付きと同じことを伝えます。

計算は `src/maeyomi/rendering/colour.py` にあり、`tests/rendering/test_palette.py` が配色をその基準に照らします。

| 検査 | 基準 | 出典 |
|---|---|---|
| 色帯の上の白文字、カラーとグレースケールの両方 | 4.5対1 | WCAG 2.2 コントラスト最低基準 |
| タイル上の絵記号、カラーとグレースケールの両方 | 3対1 | WCAG 2.2 非テキストコントラスト |
| キャラクターの色帯どうし、通常の色覚と1型・2型・3型色覚 | CIE 1976 で20 | 2色が「同じ色の濃淡」ではなく「別の色」として読める距離 |
| キャラクターの色帯どうし、グレースケール印刷時 | 1.15対1 | 見分けのつく明度差 |
| 武器と防具の使い切り版と常設版、グレースケール時 | 1.5対1 | 絵記号が共通なので、明度がより多くを担う必要がある |

2色覚のシミュレーションは Brettel・Viénot・Mollon の線形近似を使っています。シートはラスタライズしてグレースケールに変換し、その上のすべてのバーコードをデコードしているので、色を一切出せないプリンタでも通用します。

## 開発

```bash
uv run ruff format .
uv run ruff check .
uv run pyright
uv run pytest --cov
```

テストデータは `uv run python tools/fetch_fixtures.py` で作り直します。データック ドラゴンボールZ の記録は `uv run python tools/oracle/record_dbz.py` で作ります。MAME と、SHA-256 が [`artifacts.manifest.json`](artifacts.manifest.json) と一致する手持ちのカートリッジのダンプが必要です。MAME はウィンドウを開かずに動きます。 後のゲームの記録は、同じ条件で `uv run python tools/oracle/record_game.py` に `--game` を付けて作ります。

`maeyomi serve` を動かした状態で `node tools/render/layout.e2e.mjs` を実行すると、`agent-browser` で実際のブラウザを操作してページを確かめます。320ピクセルと1280ピクセルでどのタブも横にはみ出さないこと、本体の切り替えでその本体の項目が出ること、説明文が見えていて出典にリンクしていることを確かめます。
